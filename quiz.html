Build the Board

Pick a theme and set up your teams to get started. No dedicated host needed — everyone plays from the same screen.

❓ How does this work?
  1. Pick a theme and add your teams below, then tap Start Quiz.
  2. Whoever's turn it is calls out a category and point value shown in the turn banner, and taps that tile.
  3. Read the question out loud, then mark it ✅ Correct or ❌ Incorrect. A correct answer keeps the turn — an incorrect one passes it to the next team.
  4. If the timer runs out before anyone answers, a 10-second steal opens for everyone else — first to answer right steals the points and the turn.
  5. Watch for ⭐ BONUS tiles — they trigger a surprise event instead of a question.
  6. When the board is empty, the final results appear on their own.
